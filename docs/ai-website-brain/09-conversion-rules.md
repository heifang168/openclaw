# Conversion Rules

## Conversion Goal

The website should not only display information.

The main conversion goal is to turn overseas B2B visitors into qualified inquiries.

## Primary Conversion Action

The primary conversion action is:

Send an inquiry with power requirement and project information.

## Main CTA Phrases

Use these CTA phrases across the website:

- Get a Quote
- Request Technical Data
- Talk to Our Engineer
- Send Your Power Requirement
- Get Generator Configuration
- Ask for Project Support

## Required Inquiry Information

The website should encourage visitors to provide:

- Name
- Company Name
- Country
- Email
- WhatsApp / Phone
- Required Power
- Fuel Type
- Voltage
- Frequency
- Application
- Message

## Inquiry Form Fields

Recommended form fields:

1. Name
2. Company Name
3. Email
4. WhatsApp / Phone
5. Country
6. Required Power
7. Fuel Type
8. Voltage & Frequency
9. Application
10. Message

## Fuel Type Options

Fuel type options:

- Diesel
- Natural Gas
- Biogas
- LPG
- Dual Fuel
- Not Sure

## Required Power Options

Required power options:

- Below 50kVA
- 50kVA - 100kVA
- 100kVA - 500kVA
- 500kVA - 1000kVA
- 1000kVA+
- Not Sure

## Application Options

Application options:

- Factory
- Mining
- Data Center
- Hospital
- Construction
- Farm / Irrigation
- Oil & Gas
- Commercial Building
- Remote Power
- Other

## CTA Placement Rule

Every important page should include CTA sections in at least three positions:

1. Hero section
2. Middle section after product or solution explanation
3. Final section before footer

## Product Page Conversion Rule

Product pages should guide users to request:

- Product quotation
- Technical data
- Generator configuration
- Power solution recommendation

## Solution Page Conversion Rule

Solution pages should guide users to describe:

- Application scenario
- Required power
- Working environment
- Fuel type
- Country
- Voltage and frequency

## Market Page Conversion Rule

Market pages should guide users to send:

- Country
- Application
- Power range
- Fuel type
- Local working condition
- Contact information

## Final CTA Copy

Use this final CTA copy:

Need a generator solution for your project?

Tell us your required power, fuel type, voltage, frequency, country, and application. Our team will recommend a suitable generator configuration for your project.

CTA button:

Get a Quote

## Conversion Design Principle

Conversion sections should be:

- Clear
- Short
- Easy to understand
- Visible on mobile
- Not hidden at the bottom only
- Repeated across important pages

## Trust Before Conversion

Before asking for inquiry, pages should build trust through:

- Product clarity
- Application match
- Technical information
- Factory strength
- Testing process
- Project experience
- FAQ
