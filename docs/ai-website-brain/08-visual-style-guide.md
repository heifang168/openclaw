# Visual Style Guide

## Visual Positioning

The website should look like a high-end B2B industrial power website.

The visual style should communicate:

- Industrial strength
- Engineering reliability
- Global project capability
- Clean structure
- Professional trust
- High-value equipment
- Clear conversion path

## Color Direction

Primary colors:

- Black
- Dark gray
- Industrial yellow

Supporting colors:

- White
- Light gray
- Steel gray

Avoid excessive bright colors.

The website should not look colorful, childish, or decorative.

## Overall Style

The website should feel:

- Industrial
- High-end
- Reliable
- Heavy-duty
- Technical
- Global
- Professional
- Clean

## Layout Principle

Use clear B2B page layouts:

- Large hero section
- Strong headline
- Short supporting text
- Clear CTA buttons
- Grid-based product cards
- Application scenario sections
- Technical parameter tables
- Trust-building sections
- FAQ blocks
- Final CTA section

## Image Direction

Use real and realistic images whenever possible.

Preferred image types:

- Generator product photos
- Factory workshop photos
- Testing process photos
- Packing and delivery photos
- Industrial application scenes
- Mining sites
- Construction sites
- Data centers
- Oil & gas sites
- Farms and irrigation scenes
- Remote power projects

Avoid:

- Fake 3D render style
- Cartoon graphics
- Overly decorative stock images
- Low-quality blurred images
- Images that do not match the generator industry
- Overcrowded collages

## Typography Direction

Typography should be:

- Clear
- Bold for headings
- Easy to read
- B2B professional
- Not overly decorative

Headlines should be strong and direct.

Paragraphs should be concise.

## Button Style

CTA buttons should be obvious and conversion-oriented.

Recommended button labels:

- Get a Quote
- View Products
- Talk to Our Engineer
- Send Requirement

Button style:

- High contrast
- Clear border or filled style
- Easy to find
- Consistent across pages

## Homepage Visual Requirement

Homepage should have:

1. Strong industrial hero image
2. Clear product category section
3. Application scenario images
4. Factory strength section
5. Regional market section
6. Final inquiry CTA

## Product Page Visual Requirement

Product pages should have:

1. Product hero image
2. Product overview
3. Power range display
4. Application images
5. Configuration section
6. Parameter table
7. Inquiry CTA

## Avoided Visual Problems

Avoid these problems:

- Looks like a cheap template website
- Too many small text blocks
- Too many icons without real content
- Too many animations
- Poor mobile layout
- Weak CTA visibility
- No clear product hierarchy
- No trust-building content
