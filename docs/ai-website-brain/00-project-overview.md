# Project Overview

## Project Name

B2B Industrial Generator Website

## Website Type

This website is a high-end B2B industrial generator website built with Next.js, GitHub, and Vercel.

The website is not a simple company display website. It is designed to support three core business goals:

1. Traffic acquisition
2. Customer development
3. Inquiry conversion

## Business Background

The company focuses on industrial gas generator sets and diesel generator sets for overseas B2B markets.

The company is not positioned as a global giant like Schneider, Cummins, or ABB. Instead, the website should highlight flexible configuration, fast response, full project support, and cost-effective generator solutions for global industrial buyers.

## Core Website Goal

The website should help overseas customers quickly understand:

1. What generator products the company can provide
2. What power range the company can cover
3. What applications and industries the products can support
4. What markets the company serves
5. Why the company is a practical and flexible choice for B2B project buyers
6. How to quickly send an inquiry

## Technical Stack

- Framework: Next.js
- Code Repository: GitHub
- Deployment Platform: Vercel
- Content Language: English first
- Target Users: Overseas B2B buyers

## Execution Principle

All website strategy, structure, copywriting, SEO, visual rules, and conversion rules are provided by ChatGPT.

The execution agent only follows the instructions and does not create its own strategy, positioning, SEO rules, copywriting direction, or business logic.

## Website Positioning Summary

Gas & Diesel Generator Solutions for Global Industrial Projects

From 18kVA small generators to 1000kVA+ industrial power systems, the website should present flexible gas and diesel generator solutions for factories, mining, construction, data centers, farms, oil & gas projects, and remote power applications.

## Website Style

The website should look:

- Industrial
- Professional
- High-end
- Reliable
- Engineering-focused
- Global B2B oriented
- Clean and conversion-driven

The website should avoid:

- Cheap template style
- Overly domestic design style
- Too much decorative animation
- False exaggerated claims
- Overcrowded product information
- Unclear inquiry paths
