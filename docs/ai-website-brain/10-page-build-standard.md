# Page Build Standard

## Purpose

This document defines the standard for building pages in the Next.js website.

All pages must follow the B2B industrial generator website positioning, SEO requirements, visual direction, and conversion rules provided in the AI website brain documents.

## Technical Stack

- Framework: Next.js
- Deployment: Vercel
- Repository: GitHub
- Primary language: English
- Website type: B2B industrial generator website

## General Page Requirements

Every important page must include:

1. Clear page purpose
2. One H1 heading
3. SEO title
4. Meta description
5. Clear page sections
6. Buyer-oriented copywriting
7. Related internal links
8. Inquiry CTA
9. Mobile responsive layout
10. Clean B2B industrial visual style

## Page Building Principle

Do not build pages as simple text blocks.

Each page should guide the visitor through:

1. What this page is about
2. What problem it solves
3. What product or solution is suitable
4. Why the company can support the project
5. What information the buyer should provide
6. How to send an inquiry

## SEO Standard

Every important page must include:

1. SEO title
2. Meta description
3. One H1
4. Clear H2 sections
5. Natural keyword usage
6. FAQ section where appropriate
7. Internal links
8. Inquiry CTA

Do not keyword stuff.

Keywords must be used naturally and should match buyer search intent.

## Visual Standard

All pages should follow this visual direction:

- Black, dark gray, industrial yellow, white, and light gray
- High-end industrial B2B feeling
- Clear layout
- Strong hero section
- Obvious CTA buttons
- Realistic product and application images
- Clean typography
- Mobile friendly design

Avoid:

- Cheap template style
- Overly colorful design
- Too much animation
- Weak CTA visibility
- Dense text without structure
- Fake or irrelevant images

## Conversion Standard

Every important page should include CTA sections in at least three positions:

1. Hero section
2. Middle section
3. Final section before footer

Final CTA copy:

Need a generator solution for your project?

Tell us your required power, fuel type, voltage, frequency, country, and application. Our team will recommend a suitable generator configuration for your project.

CTA button:

Get a Quote

## Execution Rule

When building any page:

1. Read the relevant AI website brain documents first.
2. Follow the provided page structure.
3. Do not invent new business positioning.
4. Do not use exaggerated claims.
5. Keep English copy professional and B2B-oriented.
6. Check desktop and mobile layout.
7. Confirm build success before reporting completion.
