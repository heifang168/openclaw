# Website Structure

## Website Navigation

The website should use a clear B2B industrial navigation structure.

Recommended main navigation:

- Home
- Products
- Solutions
- Markets
- Factory
- Cases
- Resources
- About Us
- Contact

## Website Structure Principle

The website should not be a simple company brochure site.

The structure must support:

1. SEO traffic acquisition
2. Product understanding
3. Industry scenario matching
4. Regional market targeting
5. Trust building
6. Inquiry conversion

## Main Pages

### Home

Path:

/

Purpose:

The homepage should quickly communicate the company positioning, product scope, application scenarios, target markets, factory strength, and inquiry path.

Homepage sections:

1. Hero Section
2. Core Product Categories
3. Why Choose Us
4. Power Range
5. Application Solutions
6. Regional Markets
7. Factory Strength
8. Configuration Support
9. Project Cases

### Contact

Path:

/contact

Purpose:

The Contact page should focus on inquiry conversion.

Required form fields:

- Name
- Company Name
- Country
- Email
- WhatsApp / Phone
- Required Power
- Fuel Type
- Voltage & Frequency
- Application
- Message

## Footer Structure

Footer should include:

- Company short introduction
- Product links
- Solution links
- Market links
- Contact information
- Inquiry CTA

## Internal Linking Principle

Every important page should link to:

1. Related product pages
2. Related solution pages
3. Related market pages
4. Contact page

The website should guide users from information pages to inquiry pages.
